# QWE Mining by Molly Paradise — фермы BTC/ASC (Arizona RP, MoonLoader)

> **Как устроено.** Автообновление вынесено в маленький файл-загрузчик `QWE Mining.lua`, а весь код скрипта — в защищённом файле ядра `qwe_mining_core.dat` (скомпилированный байт-код LuaJIT). Загрузчик проверяет версию и сам обновляет ядро с GitHub.

## Установка
Нужны: **MoonLoader**, **SAMPFUNCS**, **mimgui**, **encoding**, **fAwesome6**.

1. Скачайте архив **qwe-mining-1.5.0.zip** со страницы [Releases](https://github.com/thepleinairstudio/qwe-mining/releases/latest) (или зелёная кнопка **Code → Download ZIP**).
2. Скопируйте содержимое папки `moonloader` из архива в папку `moonloader` игры:
   - `moonloader/QWE Mining.lua` — загрузчик (запуск и автообновление);
   - `moonloader/qwe_mining_core.dat` — ядро скрипта (защищённый байт-код, вся логика).
3. Зайдите в игру и наберите `/mine`.

Если положить только `QWE Mining.lua`, загрузчик сам скачает ядро с GitHub при первом запуске.

## Автообновление
Загрузчик `QWE Mining.lua` при запуске проверяет `version.json` в этом репозитории и, если вышло новое ядро, сам скачивает `qwe_mining_core.dat` и перезапускается. Прошлое ядро остаётся в `qwe_mining_core.dat.bak`. Отключается в настройках (раздел «Автообновление»), там же кнопка «Проверить сейчас» и история версий («Что нового?»).

## Команды
- `/mine` — главное окно, `Esc` — закрыть.
- `/minecollect` — обновить данные и собрать со всех домов.
- Суммы пополнения: `10000000`, `10кк`, `500к`.

## Вкладки
- **Фермы** — все дома плитками: видеокарты, баланс, жидкость, доход в сутки. Клик по дому — подробная карточка со сбором, заливкой и включением карт.
- **Журнал** — сборы BTC/ASC и пополнения по дням, общая статистика.
- **Пополнение** — пополнить балансы домов до максимума или на свою сумму.
- **Улучшение** — в разработке.

## Для разработки
Исходный код ядра в репозитории не публикуется. Сборка ведётся у автора: исходник (UTF-8) переводится в Windows-1251 и компилируется в байт-код `qwe_mining_core.dat` тем же LuaJIT игры; загрузчик `QWE Mining.lua` остаётся открытым.
